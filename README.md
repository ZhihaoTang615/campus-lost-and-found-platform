# Campus Lost and Found Platform

## Project Overview

This project aims to develop a web-based Campus Lost and Found Platform that helps university students report lost items, post found items, search item listings, and submit claim requests. The system is designed to make the campus lost-and-found process more organized, searchable, and accessible.

## Main Features

- Report lost items
- Report found items
- Search and filter item listings
- View item details
- Submit claim requests
- Admin review claim requests
- Update item status

## Technology Stack

- Frontend: HTML, CSS, JavaScript
- Backend: Python Flask or Node.js
- Database: MySQL
- Version Control: GitHub

## Initial Backlog Ideas

1. As a student, I want to report a lost item so that other users can help me find it.
2. As a student, I want to report a found item so that the owner can identify and claim it.
3. As a student, I want to search for lost and found items by keyword so that I can quickly find relevant items.
4. As a student, I want to filter items by category, location, and date so that I can narrow down search results.
5. As a student, I want to view item details so that I can check whether an item matches what I lost or found.
6. As a student, I want to submit a claim request for a found item so that I can recover my lost property.
7. As an administrator, I want to review claim requests so that I can reduce false or incorrect claims.
8. As an administrator, I want to update the status of an item so that users know whether it is lost, found, claimed, or returned.
9. As a student, I want to view my submitted reports so that I can track the progress of my lost or found item.
10. As a user, I want a simple and clear interface so that I can use the platform without confusion.
