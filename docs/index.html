Final Delivered Solution

Project Overview

The Campus Lost and Found Platform is a web application designed to help students report lost items, report found items, browse available records, search and filter items, and submit ownership claims for found property. Its final scope also includes user accounts, private account-owned report lists, and an administrator system for viewing lost-and-found records.

The platform improves campus lost-and-found management through a simple and user-friendly interface supported by a Flask backend and MySQL database.

Lecturer-requested final scope refinement: "The final version should include a user system and an administrator system that can be used to view lost-and-found records."

The implemented refinement provides registration, login, POST-only logout, required ownership for every new item and claim, My Reports, and a read-only Admin Dashboard. All operational lost-and-found routes require login. The Iteration 3 record that deferred US08-US11 is retained as historical evidence; the later refinement now delivers the view-only US11 slice. US08 and US10 remain deferred. US09 also remains deferred because the administrator can view claims but cannot approve, reject, delete, or update them.

Pre-enhancement item and claim rows remain valid with a null account owner. The administrator view uses left joins so those legacy rows remain visible. The current application does not create new unowned rows. Runtime uploads are excluded from new Git tracking by the repository ignore rules.

Delivered Solution Summary

The final delivered system supports reporting, browsing, searching, filtering, viewing, photographing, and claiming lost-and-found items. It also supports registration and login, account-owned report viewing, and a read-only administrator overview of all item and claim records. Current source and the 95-pass automated suite support the unchanged US01-US07 baseline and the final refinement. Selected historical manual evidence records MySQL persistence; deferred workflow scope and unresolved evidence gaps remain explicit.
