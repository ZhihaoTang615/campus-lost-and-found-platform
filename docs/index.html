Project Overview

The Campus Lost and Found Platform is a web application designed to help students report lost items, report found items, browse available records, and submit ownership claims for found property. The platform improves the efficiency of campus lost-and-found management through a simple and user-friendly interface supported by a Flask backend and MySQL database.

  • Report Found Item
  • Browse Items
  • Search Items
  • Filter Items
  • Item Details
