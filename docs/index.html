CP3407 Advanced Software Engineering

Final Delivered Solution

Project Overview

The Campus Lost and Found Platform is a web application designed to help students report lost items, report found items, browse available records, search and filter item information, and submit ownership claims for found property.

The platform improves campus lost-and-found management through a simple and user-friendly interface supported by a Flask backend and MySQL database.

Delivered Features

  • Report Lost Item
  • Report Found Item
  • Browse Items
  • Search Items
  • Filter Items
  • Item Details
  • Uploaded Photo Display
  • Submit Claim Request
