# User Flow Diagram

This diagram illustrates how users navigate through the Campus Lost and Found Platform.

![User Flow Diagram](images/user-flow-diagram.png)

## Main User Flows

### Report Lost Item

Homepage
→ Report Lost Item
→ Fill Form
→ Submit Report
→ Confirmation Message

### Report Found Item

Homepage
→ Report Found Item
→ Fill Form
→ Submit Report
→ Confirmation Message

### View Item Details

Homepage
→ View Item Details
→ Read Information
→ Return Homepage

## Purpose

The user flow is designed to minimize navigation complexity and allow students to complete tasks quickly.
