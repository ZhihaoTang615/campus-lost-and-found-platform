# Iteration 1 Client Feedback

## Prototype Demonstrated

The Iteration 1 runnable prototype was demonstrated to three university students. The purpose of the demonstration was to collect client feedback before starting Iteration 2.

The following completed user stories were shown:

* **US01 – Report Lost Item**
* **US02 – Report Found Item**
* **US05 – View Item Details**

The demonstrated prototype included:

* A homepage with navigation links
* A lost-item report form
* A found-item report form
* An Item Details page showing a sample black wallet

| Participant | Positive Feedback                                                                                   | Suggested Improvement                                                        |
| ----------- | --------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------- |

## Common Findings

The students generally understood the purpose of the platform from the homepage. They found the navigation links clear and the report forms easy to complete.

The repeated findings were:

* The current prototype is simple and easy to use.
* The report forms include the basic information needed for lost and found items.
* An item photo upload function would make it easier to identify similar items.
* Search and filter functions would help users locate relevant reports more quickly.
* A clearer claim process should be added after a user finds a possible matching item.

## Recommended Changes for Iteration 2

Based on the client feedback, the following improvements should be considered for Iteration 2:

1. Add an item photo upload function to the lost-item and found-item forms.
2. Add keyword search and filters for category, location, and date.
3. Add a claim-request button on the Item Details page.
4. Allow users to track the status of their claim requests.
5. Improve the visual layout and spacing so that the pages are easier to scan.

The planned Iteration 2 user stories already include:

* **US03 – Search Items**
* **US04 – Filter Items**
* **US06 – Upload Item Photo**
* **US07 – Submit Claim Request**

The claim-status tracking feature can be developed further in Iteration 3 under:

* **US08 – Track Claim Status**
