# Iteration 2 Client Feedback

## Prototype Demonstrated

The Iteration 2 runnable prototype was demonstrated to three university students. The prototype included the main user stories developed for Iteration 2:

* **US03 – Search Items**
* **US04 – Filter Items**
* **US06 – Upload Item Photo**
* **US07 – Submit Claim Request**

The purpose of the feedback session was to evaluate the prototype from three main aspects:

1. Functionality
2. Appearance and UI design
3. Reasonableness of the user flow

## Common Findings

The participants generally agreed that the Iteration 2 prototype improved the platform compared with Iteration 1. The new functions made the website more practical because users could search for items, filter results, upload photos, and submit claim requests.

The common findings were:

* The search and filter functions made it easier to find relevant lost or found items.
* The photo-upload function helped users identify items more clearly.
* The claim-request process was understandable and matched the purpose of the platform.
* The interface was simple and easy to read.
* Some layout spacing and visual consistency could still be improved.
* Users wanted clearer confirmation after submitting a report or claim request.
* Claim-status tracking should be considered for the next iteration.

## Recommended Changes for Iteration 3

Based on the feedback, the following improvements should be considered for Iteration 3:

1. Add claim-status tracking so users can see whether their request is pending, approved, rejected, or completed.
2. Improve the visual spacing between forms, buttons, and item cards.
3. Add clearer confirmation messages after submitting reports or claim requests.
4. Improve the consistency of colours, buttons, and page layout.
5. Allow users to view their own submitted reports.
6. Add an admin or reviewer function to review claim requests.

These recommendations support the planned Iteration 3 user stories:

* **US08 – Track Claim Status**
* **US09 – Review Claim Requests**
* **US10 – Update Item Status**
* **US11 – View My Submitted Reports**
