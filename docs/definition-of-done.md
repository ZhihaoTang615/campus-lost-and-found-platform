# Final Clarified Definition of Done

This checklist is the team's final clarification of what “Done” should mean. It
does not claim that every historical story satisfied every item.

A story is Done when:

- [ ] its agreed acceptance criteria are satisfied;
- [ ] implementation is complete for the agreed scope;
- [ ] relevant automated tests pass;
- [ ] relevant manual or system tests pass;
- [ ] database behaviour is verified where applicable;
- [ ] code is reviewed through a Pull Request where repository evidence exists;
- [ ] documentation and evidence are updated;
- [ ] no known critical defect remains;
- [ ] the related work is moved to Done on the Project Board; and
- [ ] deferred work is explicitly returned to the backlog.

Where a checklist item cannot be evidenced, it must remain an open verification
item rather than being inferred from implementation alone.
