# Final Acceptance-Test Matrix

## Purpose and status basis

This matrix consolidates acceptance evidence for the delivered final Campus
Lost and Found Platform: the US01–US07 baseline plus the lecturer-requested
user and read-only administrator enhancement. For US04, the accepted final
scope is report-type filtering, category filtering, and keyword search support,
including their combined use. Location, date, and status filters are not part
of the delivered scope.

The final status in each row is based on the current implementation, the
repository's **95-passed** automated regression record, and the cited supporting
artefacts. The automated tests use fake or mocked database connections; manual
screenshots are demonstration evidence rather than a newly witnessed live-MySQL
acceptance cycle. See [Final Testing Evidence](final-testing-evidence.md) for
those boundaries and the screenshot privacy review.

## Acceptance conclusion

All confirmed final-scope rows above are delivered and covered by the current
automated regression record. This matrix does not expand acceptance to US08,
state-changing US09, US10, report editing, claim decisions, or administrator
record mutation. Manual artefacts that expose personal or local-development
context must be redacted or replaced before public submission, as catalogued in
[Final Testing Evidence](final-testing-evidence.md#privacy-and-evidence-check).
